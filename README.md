# 🎨 Alca Canva

Web-based design editor — build with pure HTML/CSS/JS.

**Credits:** AlcaW44  
**Saluran WA:** https://www.whatsapp.com/channel/0029Vb82nkLEwEjtLSQ49I44

## Fitur
- Multi-layer canvas editor
- Text formatting lengkap (font, size, bold, italic, shadow, outline, align, color, rotation, opacity)
- Shapes: rect, circle, triangle, star, diamond, hexagon, pentagon, line
- Icons emoji
- Upload gambar + layer image
- Background solid & gradient
- Layer panel (reorder, lock, hide, duplicate, delete)
- Undo/redo history
- Zoom in/out/fit
- Export PNG/JPEG/WebP
- Keyboard shortcuts (Ctrl+Z, Ctrl+Y, Ctrl+D, Delete, Esc, +, -)
- Responsive + mobile-friendly
- Dark UI ala Alca Studio

## Development

    npm install
    npm run dev

Buka http://localhost:3000

## Deploy ke Vercel

    npm run deploy

Atau import repo di https://vercel.com/new
